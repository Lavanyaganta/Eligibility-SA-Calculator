# HDFC Life Sum Assured Calculator

A Streamlit-based internal calculator to estimate the indicative eligible Sum Assured for customers based on age, annual income, and existing life cover.

## Features
- Customer validation
- Age-based eligibility multiples
- Indian currency formatting
- Amount displayed in words
- Internal disclaimer
- Responsive Streamlit UI

## Tech Stack
- Python
- Streamlit
- num2words
